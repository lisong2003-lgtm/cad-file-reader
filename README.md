# CAD File Reader（CAD 图纸读取与方案统计）

一个给 AI 编码助手（Codex / Claude Code / 兼容 Agent）使用的**读图与统计**工具型 Skill：直接读取 DWG/DXF/DWT，不需要安装 CAD 软件。给它一张结构施工图，它返回梁、板、柱、墙各截面尺寸有多少个构件型、根数估计及其依据、板厚档、箍筋与纵筋型号汇总；**0.2.0 起可以只取指定楼层**（给图名即出该层清单），每条数都带图层、图框与坐标可回图核对。

> 定位说明：这是读图统计工具，不是算量工具。它不输出混凝土方量与钢筋重量——图面不写构件长度，方量要靠结构建模或翻样软件；包内的"梁砼估算"等一律是 `长度×截面` 级粗算，只作参考。

> 身份透明：本包是 AI 编码助手调用的工具型 Skill，不扮演任何人物或外部产品身份；被询问时应如实说明自己是 AI 助手。

## 能力

- 直接读取 DWG / DXF / DWT，支持单文件、目录和递归扫描。
- 低内存快速路径：只解文字、图层、块名，适合几十 MB 大图。
- 构件识别：梁、板、柱、墙、基础、门窗。
- **按楼层取数（0.2.0）**：`--floor-label "二层梁平法施工图"` 只统计该层图框，不依赖特定图层命名。
- **图层归属（0.2.0）**：每条文字带图层名，能区分目录页图名与真图框图名、集中标注与原位标注，同一根梁不再被平面+剖面+大样重复计数。
- **全量台账（0.2.0）**：`--detail-json 文件.json` 导出文字/图层/坐标/图框，便于二次核对。
- **可复现（0.2.0）**：同一命令两次运行的图框编号与坐标范围一致；文字数超上限时在报告顶部显式告警，不再静默截断。
- 梁：类型、根数、跨数、悬挑、截面、箍筋、纵筋、梁长估算、梁砼估算。
- 柱：类型、根数、截面、箍筋、纵筋、柱高、柱砼估算。
- 板：轴线面积、板厚、板砼估算。
- 钢筋型号汇总：`-rebar.csv`。
- 建筑做法提取：屋面、楼面、地面、墙面、顶棚、防水、保温等，`-practices.csv`。
- 图纸检索：`--search` / `--filter`，输出文件、图框、图层、坐标。
- DWG→DXF：内置 `ezdwg 0.12.6`，不需要 LibreDWG / ODA。
- SVG 预览：`read_cad.sh --render`。
- 内存看门狗：大图超限自动终止，防止解析器把机器拖到卡死。

## 安装（GitHub 完整包）

```bash
cp -R cad-file-reader "$CODEX_HOME/skills/"

# Python 环境需要 Python 3.10+；Codex bundled runtime 自带 numpy
# 普通 Python 环境缺少 numpy 时执行：
python3 -m pip install numpy
```

GitHub 完整包已内置 `vendor/`（ezdwg、ezdxf、fontTools、pyparsing），不需要额外下载 CAD 解析依赖。

## 安装（SkillHub 轻量包）

SkillHub 版为纯文本合规包，不含 `vendor/` 二进制/编译文件。安装后先执行一次：

```bash
cd "$CODEX_HOME/skills/cad-file-reader"
scripts/install_vendor.sh
```

该命令从 GitHub Release 下载与完整包一致的 `vendor/` 依赖。

> 版本差异：GitHub 完整包解压即用；SkillHub 轻量包多一步下载 `vendor/`，安装后功能一致。

## 使用

```bash
cd "$CODEX_HOME/skills/cad-file-reader"

# 方案统计：梁/板/柱 + 配筋 + 混凝土方量 + 建筑做法 + 规格表
scripts/cad_scan.sh 图纸.dwg --only 梁,板,柱 \
  --with-mtext --with-geom --cluster 1500 \
  --axis-grid "7x8000,5x7500" --thk-mm 120 --col-height-mm 3000 \
  --spec-table --format all -o 结果/结构统计

# 按楼层取数：只统计指定图名那一层
scripts/cad_scan.sh 图纸.dwg --floor-label "三层梁平法施工图" --with-mtext -o 三层统计

# 图纸检索：查说明、查规格、查编号
scripts/cad_scan.sh 图纸.dwg --search "屋面做法|C30|KZ1"

# DWG 转 DXF
scripts/convert_dwg.sh 图纸.dwg --out 图纸.dxf

# 全量读取并生成 SVG 预览
scripts/read_cad.sh 图纸.dxf --json --render --render-dir 预览
```

## 输出文件

- `-md`：人类可读统计报告。
- `.json`：结构化结果，供后续计算。
- `.csv`：构件明细。
- `-rebar.csv`：钢筋型号汇总。
- `-practices.csv`：建筑做法清单。
- `-concrete.csv`：梁砼、柱砼、板砼、合计。
- `-spec.csv`：混凝土等级、板厚、保护层、抗震等级。
- `-axis.csv`：轴线面积与板砼估算。
- `--detail-json` 指定的文件：全量文字台账（内容、图层、坐标、图框），0.2.0 新增。

## 实测

2026-08-31 合成样例（本包自带最小样例，不属于任何真实工程）：

- 梁：按集中标注给出截面（宽×高）、跨数与悬挑，根数估计随附"依据"列。
- 柱：给出编号、截面与配筋；柱高需按实际层高传 `--col-height-mm`。
- 板：给出板厚档与轴线面积估算入口。
- 建筑做法：屋面、楼面、地面、墙面均可提取。
- 检索：同一编号的多个坐标位置全部列出，便于回图核对。

## 0.2.0 实测（本机，24 MB 结构施工图，约 6.4 万条文字）

- 单层取数耗时 ≈ 25 秒，峰值内存 ≈ 117 MB；同一命令跑两遍，报告正文逐字一致（只有内存读数差 1 MB）。
- 目录页同名图名被正确排除；同册存在两份图框集时命中 2 个图框并给出"会算两遍"的告警。
- 单测 5 项（合成文字，不含任何真实图纸）全部通过：目标层只留本框、目录不计、副本告警、找不到不丢数、半径可覆盖。

## 限制

- 识别基于图纸文字规则，不是结构拓扑；天正自定义实体、丢字符字体可能识别不到。
- 梁长、根数、方量均为估算，不替代翻样和正式算量。
- 柱高通常不在平面图中，需要按实际层高传 `--col-height-mm`。
- 板砼按轴线面积×板厚，不扣柱、墙、洞口。
- 钢筋只统计型号/根数，不计算重量和下料长度；混凝土只给粗算，不出正式方量。
- 楼层取数按图框分堆：没有图框块可定位时按"整框 + 最近图名"归属，边界处可能少计，报告里列出纳入/排除条数供自查。
- 部分设计院的柱表/墙表格式下，柱与墙截面可能取不到（只出编号与根数）。
- 建筑说明常用 MTEXT，检索和做法提取需加 `--with-mtext`。
